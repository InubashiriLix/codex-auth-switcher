# Contributing

Thanks for helping improve Codex Switcher.

- Keep changes focused and explain user-facing behavior.
- Never include tokens, live emails, home paths, or real account snapshots in commits, screenshots, or logs.
- Run `cargo fmt --check`, `cargo test`, and `cargo build --release`.
- Update the README when commands, keybindings, or security behavior change.

Bug reports, theme ideas, and documentation fixes are welcome. Redact all credentials and personal data before posting.
